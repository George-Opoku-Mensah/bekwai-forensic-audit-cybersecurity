# bekwai-forensic-audit-cybersecurity
** Accounting with Computing | KSTU**
## 🎯 Objective
Detect financial fraud and anomalies in Bekwai Municipal Assembly expenses (2024-2025) using forensic accounting techniques.
## 📊 Dataset
- Sanitation: GHS 60,583
- Administration: GHS 55,800
- Roads: GHS 54,800
- Education: GHS 51,900
- Health: GHS 51,100
## 🚨 Fraud Detection Techniques Used
1. **Round Number Bias** - Fraudsters use round numbers (55,800, 54,800)
2. **Threshold Analysis** - Expenses just below approval limit (GHS 60k)
3. **Duplicate Invoice Check** - Sanitation highest, needs verification
4. **Benford's Law** - First digit analysis
## 📈 Findings
- **Sanitation (85% Risk):** Flagged - Highest amount, possible duplicate invoice
- **Roads (78% Risk):** Flagged - Just below GHS 55k threshold
- **Administration (42% Risk):** Mediu
- Round number bias
- **Education & Health:** Clean (25-30% risk)
## 🛠️ Tools
- Excel, Power BI, Python (Pandas, Matplotlib)
- Forensic Accounting + Cybersecurity principles
## 🔐 Cybersecurity Link
This project demonstrates **Financial Cybercrime Detection** - same techniques used to detect MoMo fraud, payroll fraud, and procurement fraud in Ghana.
